# نظام إدارة محطة وقود

تطبيق ويب PHP لإدارة عمليات محطة الوقود، ويشمل الحسابات والعملاء والموردين والخزانات والمضخات والقراءات والمبيعات والمصروفات والورديات والتقارير.

## المتطلبات

- PHP مع PDO MySQL مفعّل.
- MySQL أو MariaDB.
- خادم ويب مثل Apache أو Nginx مع PHP-FPM.

## الإعداد

1. أنشئ قاعدة بيانات MySQL/MariaDB فارغة.
2. استورد المخطط من `fuel_station_2_.sql`. يحتوي الملف المنشور على بنية الجداول والقيود فقط، ولا يحتوي سجلات العملاء أو الموظفين أو المعاملات.
3. اضبط متغيرات البيئة `DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD` في بيئة خادم الويب/PHP-FPM. ملف `.env.example` مرجع للأسماء فقط؛ لا يقرأ التطبيق ملف .env تلقائياً.
4. اجعل مجلد المشروع متاحاً من خادم الويب ثم افتح `index.php`.

## الأمان

- لا تستخدم حساب قاعدة البيانات `root` للتطبيق؛ أنشئ مستخدماً محدود الصلاحيات.
- لا ترفع بيانات اتصال قاعدة البيانات أو نسخ قواعد بيانات الإنتاج.
- استخدم بيانات تجريبية مجهولة الهوية عند إعداد عرض توضيحي.
- إذا سبق نشر بيانات حقيقية أو كلمات مرور، فقم بتدويرها ومراجعة سجل Git؛ حذفها من آخر نسخة لا يمحوها من تاريخ المستودع.
