# نظام إدارة محطة وقود

تطبيق ويب PHP لإدارة عمليات محطة الوقود، ويشمل الحسابات والعملاء والموردين والخزانات والمضخات والقراءات والمبيعات والمصروفات والورديات والتقارير.

## المتطلبات

- PHP مع خادم ويب مثل Apache.
- MySQL أو MariaDB.

## الإعداد

1. أنشئ قاعدة بيانات MySQL جديدة.
2. استورد المخطط والبيانات الأولية من `fuel_station_2_.sql`.
3. عدّل إعدادات الاتصال بقاعدة البيانات في ملفات الإعداد ضمن `config/` أو `includes/` بحسب بيئتك.
4. اجعل مجلد المشروع متاحاً من خادم الويب ثم افتح `index.php`.
